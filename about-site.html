07 — ABOUT THIS SITE

Behind
The Website.

Sebuah laman web yang dibangunkan untuk meneroka perjalanan, perniagaan dan pencapaian Khairul Aming.

01 — THE PROJECT

Why I chose
Khairul Aming.

Saya memilih Khairul Aming sebagai individu inspirasi kerana perjalanan beliau menunjukkan bagaimana minat terhadap sesuatu bidang boleh berkembang menjadi kerjaya, perniagaan dan satu jenama yang mempunyai identiti tersendiri.

Website ini direka untuk menceritakan perjalanan tersebut secara visual — daripada permulaan sebagai pencipta kandungan, perkembangan produk makanan, pencapaian dan pengembangan kepada perniagaan restoran.

02 — DESIGN CONCEPT

Dark. Bold.
Purposeful.

Konsep visual laman ini menggunakan pendekatan minimal, moden dan cinematic untuk mencerminkan identiti Khairul Aming sebagai pencipta kandungan dan usahawan.

01

Black

Memberikan suasana premium dan menjadikan kandungan visual lebih menonjol.

02

Yellow

Digunakan sebagai warna accent untuk menarik perhatian kepada perkara penting.

03

Typography

Saiz teks yang besar digunakan untuk menghasilkan visual yang berani dan mudah dikenali.

04

Visual

Gambar dan video digunakan untuk menjadikan perjalanan lebih menarik dan mudah difahami.

03 — WEBSITE STRUCTURE

Seven pages.
One story.

01

Utama

Memperkenalkan konsep utama dan nilai yang menjadi identiti laman.

02

Biografi

Menerangkan latar belakang dan permulaan perjalanan Khairul Aming.

03

Perjalanan

Memaparkan perkembangan penting mengikut timeline.

04

Perniagaan

Memfokuskan produk, business model dan perkembangan Rembayung.

05

Pencapaian

Menunjukkan pengiktirafan dan pencapaian utama.

06

Galeri

Mengumpulkan gambar dan video dalam bentuk visual gallery.

07

Tentang Laman

Menerangkan konsep, struktur dan proses pembangunan website.

04 — TOOLS & TECHNOLOGY

Built with
purpose.

HTML STRUCTURE

Digunakan untuk membina struktur dan kandungan setiap halaman website.

CSS DESIGN

Digunakan untuk mengawal warna, typography, layout, animation dan responsive design.

DREAMWEAVER DEVELOPMENT

Digunakan sebagai platform utama untuk membina, mengurus dan preview website.

MULTIMEDIA EXPERIENCE

Gambar dan video digunakan untuk menjadikan pengalaman pengguna lebih interaktif.

05 — REFLECTION

What I
learned.

Projek ini membantu saya memahami bahawa pembangunan website bukan hanya tentang menulis code, tetapi juga melibatkan perancangan, pemilihan visual, susunan kandungan dan pengalaman pengguna.

Saya juga belajar menggunakan HTML dan CSS dengan lebih yakin serta memahami bagaimana perubahan kecil pada layout, warna dan typography boleh mengubah keseluruhan penampilan sesebuah website.

Penggunaan Adobe Dreamweaver membantu saya melihat hubungan antara struktur HTML, styling CSS dan hasil akhir website melalui proses preview dan testing.
